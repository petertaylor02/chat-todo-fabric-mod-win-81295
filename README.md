## Overview

Chat ToDo List Fabric Mod is a client-side utility for Minecraft Java on Fabric that turns chat into a lightweight task manager. It is designed around task tracking inside the game, letting you manage to-do items through chat-based interactions instead of switching to external tools.

The mod focuses on checklist-style progression and local JSON editing so task lists can be organized and updated from your own setup. It is built for players who want a Minecraft-oriented workflow for keeping track of objectives, steps, or repeating tasks during play.
